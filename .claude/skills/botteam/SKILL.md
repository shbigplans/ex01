# 봇팀 (Bot Team) 파이프라인

사용자가 `/botteam <주제>` 또는 "봇팀 가동: <주제>" 라고 하면 아래 절차를 그대로 수행한다.
사용자는 20년차 개발자이며 100만 구독자 유튜브 채널 운영자다. 결과물은 상용 수준이어야 한다.

## 0. 킥오프 (오케스트레이터 = 나)

1. 주제를 한 문단으로 재정의하고, 프로젝트 유형을 판별한다. 명시가 없으면 **홈페이지 제작**으로 간주한다.
2. 아래 봇 구성을 사용자에게 표로 보여주고, 사용자가 별도 지시가 없으면 바로 진행한다(확인 질문으로 멈추지 않는다).
3. 작업 로그는 `docs/botteam/<주제-slug>/` 아래에 남긴다.
   - `00-brief.md` : 재정의된 요구사항
   - `01-plan.md` : A봇 기획안
   - `02-design.md` : B봇 디자인 결정 사항 + 디자인 캔버스 링크
   - `03-dev-log.md` : C봇 구현 로그
   - `04-qa.md` : D봇 QA/리뷰 결과
   - `05-conversation.md` : 봇 간 대화 요약(라운드별)

## 1. 봇 역할

| 봇 | 역할 | 실행 방법 |
|---|---|---|
| A봇 | PM/기획. 요구사항, 사이트맵, 페이지별 섹션 구성, 카피 초안 | `Agent` (subagent_type: Plan 또는 general-purpose) |
| B봇 | 디자인. **`design` 스킬(Claude Design)** 로 디자인 캔버스(.dc.html 아트보드) 제작, 컬러/타이포/레이아웃 확정 | 오케스트레이터가 `Skill(design)` 호출 후 결과를 B봇 산출물로 기록 |
| C봇 | 개발. 디자인 캔버스를 기준으로 실제 코드 구현 | `Agent` (general-purpose) |
| D봇 | QA/리뷰. 빌드 · 반응형 · 접근성 · 링크 · 성능 점검, 코드 리뷰 | `Agent` (general-purpose), 필요 시 `code-review` 스킬 |
| E봇 (선택) | 마케팅/SEO/유튜브 연동. 메타태그, OG 이미지, 채널 유입 동선 | `Agent` (general-purpose) |

봇은 각각 독립 컨텍스트로 실행한다. 서로의 산출물은 `docs/botteam/` 파일과 `SendMessage` 로 주고받는다.

## 2. 대화 루프

1. **Round 1** : A봇 기획 → B봇 디자인 → C봇 구현 → D봇 QA
2. **Round 2~3** : D봇 지적 사항을 C봇이 수정, 디자인 이슈는 B봇이 수정. 최대 3라운드.
3. 3라운드 안에 합의가 안 되면 오케스트레이터가 결정하고 이유를 `05-conversation.md` 에 기록한다.
4. 각 라운드 종료 시 사용자에게 3~5줄 진행 요약을 보낸다.

## 3. 홈페이지 제작 기본값

사용자가 스택을 지정하지 않으면:

- 정적 사이트: HTML + CSS + 최소 JS (프레임워크 없음). 배포 단순화 우선.
- 동적 요구가 있으면: Next.js(App Router) + Tailwind.
- 반드시 포함: 반응형(400px~1440px), 다크/라이트 모드, OG/메타 태그, favicon, 접근성 기본(alt, contrast, focus).
- 유튜브 채널 운영자용 홈페이지라면: 채널 구독 CTA, 최신 영상 섹션, 소셜 링크, 비즈니스 문의 폼을 기본 포함.

## 4. 종료 조건

- D봇 QA 통과 (빌드 성공, 콘솔 에러 0, 반응형 확인)
- 디자인 캔버스 Artifact 링크 + 완성 페이지 Artifact 링크를 사용자에게 전달
- 지정 브랜치에 커밋 · 푸시 (커밋 메시지는 라운드 단위로)
- 최종 요약: 만든 것 / 봇 간 주요 결정 / 남은 이슈 / 다음 단계

## 5. 금지 사항

- 외부 배포, 결제, 도메인 구매 등 되돌리기 어려운 작업은 봇에게 맡기지 않고 사용자 확인을 받는다.
- 봇 간 대화를 실제로 실행하지 않고 흉내만 내서 보고하지 않는다.
- 사용자가 "워크플로우로 돌려줘" 또는 "ultracode" 라고 명시하지 않는 한 `Workflow` 도구는 쓰지 않고 `Agent` 로 소규모 병렬 실행한다.
