## 4. 헤딩·alt·앵커 점검 결과 → C봇 제안

### 4-1. 헤딩 구조
- h1 은 전 페이지 1개(자동 검증 통과). 문제는 **h1 에 검색어가 없는 페이지**:
  - `relation.html` h1 `다시, 우리.` — 브랜드 카피로는 좋지만 검색엔진엔 무의미. 제안: h1 유지하되 바로 아래 lead 를 `부부 싸움, 아이에게 소리친 뒤의 후회 — 상처가 폭발이 되기 전에 마음을 말하는 법을 훈련합니다.` 처럼 검색어를 품게 하거나, h1 을 `다시, 우리. — 부부·부모자녀 화 조절 훈련` 으로 확장(디자인 판단은 B봇).
  - `ai-coach.html` h1 `감정과 행동 사이에 틈을 만드는 4단계` — 페이지의 고유명 "AI 마음브레이크 코치"가 eyebrow(`<span>`)에만 있음. 제안: h1 `AI 마음브레이크 코치 — 감정과 행동 사이에 틈을 만드는 4단계`.
  - `checkup.html` h1 `지금 내 마음근력은 어디에 있을까요.` — 제안: eyebrow 의 "마음근력 자가진단"을 h1 에 포함.
- `ai-coach.html` 사이드 카드 `h2 v1 · 규칙 기반` → `h3 Claude API 연동` 은 개발 정보가 헤딩 계층을 차지. 제안: 두 카드 헤딩을 `<p class="card__title">` 로 내리거나, h2 하나 `작동 방식` 아래 h3 2개.
- `money.html` 프로그램 섹션의 h2 가 카드 안에 있음(`<h2 id="program-title" class="card__title">`) — 시각적으론 카드 제목이지만 문서 아웃라인상 "머니 마음근력 개인 코칭" h2 가 되어 오히려 좋음. 유지.
- **푸터의 `<h2>프로그램/도구/소개·문의</h2>`** 가 9페이지 모두에서 본문 h2 와 동급으로 잡힘(페이지당 h2 3개 추가). 제안: 푸터 컬럼 제목을 `<p class="site-footer__heading">` 또는 `<h3>` 로 강등(components.css 셀렉터만 바꾸면 됨). 우선순위 중.

### 4-2. 이미지 alt
- 현재 실제 `<img>` 0개. 인물·저서 자리는 `role="img" aria-label="[교체: …]"` 플레이스홀더 — 스크린리더가 "[교체: 나영채 코치 프로필 사진…]" 을 읽음. 교체 시 alt 확정안:
  - 프로필: `alt="나영채 감정·충동조절 마음근력 코치 프로필 사진"`
  - 저서: `alt="나영채 저서 『상처를 넘어설 용기』 표지"`
  - 파일명도 검색용으로: `na-youngchae-coach.jpg`, `book-courage-beyond-wounds.jpg`(영문 슬러그, 한글 파일명 금지). `width/height` 속성 명시(CLS), `loading="lazy"` 는 히어로 제외.
- 흐름도 `div.flow[aria-label]` 은 텍스트 노드가 있으므로 aria-label 유지 OK.

### 4-3. 내부 링크 앵커 텍스트

## 5. 전환 동선 리뷰 (유튜브 운영자 관점)

### 5-1. 히어로 CTA
- 현재: 주 `AI 마음브레이크 체험하기` / 부 `내 마음근력 진단하기`. 방향은 맞다(상담 문턱을 도구로 낮추는 기획 §1-2). 다만 "AI 마음브레이크"는 처음 온 사람에게 **낯선 고유명사** — 클릭 이유가 안 보인다.
- 제안(A/B 후보, 카피는 C봇/A봇 확정):
  - A: `화 나는 지금, 60초 멈춤 연습하기` (행동+시간 명시)
  - B: `2분 자가진단으로 내 패턴 보기` 를 주 CTA 로, AI 코치를 부 CTA 로 — 페르소나 A(관계)의 첫 전환이 자가진단이라는 기획 §1-2 와 일치. 페르소나 B(머니)는 money 페이지 히어로에서 이미 `충동 직전, AI 코치` 가 주 CTA 이므로 트랙별로 다르게 가져가도 됨.
  - CTA 아래 마이크로카피 1줄: `가입·저장 없음 · 약 2분` (이탈 요인 "부담" 제거).
- 히어로 인물 사진이 `[교체]` 인 상태로 배포되면 신뢰가 0 이 된다. 사진 확보 전이라면 히어로 우측을 흐름도(relation/money 처럼)로 바꾸는 폴백을 C봇에 요청.

### 5-2. 자가진단 → 상담 신청 흐름
- 잘 된 것: 결과 → `상담 신청` 시 `?result=R-23` 자동 채움, 실명 불필요.
- 이탈 지점:
  1. 결과 화면의 추천 프로그램에 `[교체: 회기]` 가 그대로 노출됨(checkup.js). 값 확정 전에는 회기 문구 자체를 숨기는 조건 처리 제안.
  2. "안정" 구간 사용자는 상담 CTA 가 약해도 된다 — 대신 **유튜브 구독/카카오 채널 추가** CTA 를 두어 리드로 남기기(§6). 현재는 안정 구간에서도 상담 신청만 있어 아무것도 안 하고 나간다.
  3. 결과 공유 해시(`#result=R-23`)는 좋은 바이럴 장치. 공유 버튼에 **카카오톡 공유** 를 1순위로(한국 트래픽의 대부분이 카톡 링크). Kakao SDK 없이도 `https://sharer.kakao.com/talk/friends/picker/link?url=…` 는 안 되므로 SDK 필요 → C봇 판단. 최소한 "링크 복사" 버튼은 이미 있으니 OK.
  4. 결과 리포트에 **"오늘 바로 할 것 1개"** (AI 코치 CHOOSE 선택지 중 하나)를 노출하면 상담 전 가치 체험 → 상담 전환율 상승. 기획 §1-2 "오늘 당장 써먹을 기술 1개" 요구와 일치.

### 5-3. 상담 신청 폼 이탈 요인
- 필수 항목이 이름·연락처·트랙·대상·동의 5개 → 적절. 다만:
  1. **전화번호 필수 + 이메일 선택** 은 "정신과·낙인" 걸림돌(§1-2)이 있는 머니 페르소나에게 부담. 제안: 연락처를 "전화 또는 카카오톡 ID 또는 이메일 중 1개" 로 완화(검증 로직 변경 → C봇).
  2. `상담 형식` 옆에 `[교체: 제공 형식 확정]` 이 사용자에게 보임 — 확정 전에는 fieldset 자체를 숨기기.
  3. 폼 상단에 **"제출 후 어떻게 되는지"** 3단계(접수 → `[교체: 회신 시간]` 내 연락 → 첫 상담) 를 미리 보여주면 완료율이 오른다. 현재는 제출 후 메시지에만 있음.
  4. 엔드포인트 미설정 상태(현재)에서는 "전송 경로 미설정 + 복사" 모드 → **배포 전 반드시 Formspree/Netlify Forms 연결**. 미연결 배포는 전환 0.
  5. 강의 문의 폼의 `예산 범위` select 에 `[교체: 구간]` 옵션이 그대로 노출 — 확정 전 `미정` 만 남기기.
  6. 폼 완료 페이지/메시지에 "기다리는 동안 AI 코치 해보기" + 유튜브 영상 1개 링크 → 대기 이탈 방지.

### 5-4. "유튜브 채널/영상 섹션" 설계안 (브리프에 채널 정보 없음 → 플레이스홀더만)
- 위치: index S7(왜 나영채인가) 과 S8(프로그램) 사이에 **S7b "영상으로 먼저 만나기"** 1섹션. about.html 의 "강의·미디어" 섹션에도 동일 컴포넌트 재사용.
- 구성:
  ```
  h2  영상으로 먼저 만나기
  p   상담 전에 코치의 말투와 방법을 확인하세요.   ← 신뢰 형성 목적 명시
  [영상 카드 3개: 16:9 썸네일 + 제목 + 길이]
     썸네일은 <img> (lazy) + 클릭 시 youtube-nocookie.com 임베드(iframe 은 클릭 전 로드 금지 — LCP 보호)
     [교체: 유튜브 영상 ID 1~3]  제목 [교체]  길이 [교체]
  버튼  채널 구독하기 → [교체: 유튜브 채널 URL]?sub_confirmation=1
  ```
- 영상 선정 기준(플레이스홀더 채울 때): ① 마음브레이크 4단계 설명 영상 ② 관계 사례 영상 ③ 머니 사례 영상 — 두 트랙 대칭.
- 구조화 데이터: 채널 확정 시 Organization/Person `sameAs` 에 채널 URL 추가, 임베드 영상엔 `VideoObject`(name, description, thumbnailUrl, uploadDate, embedUrl) — E봇 후속.
- 유튜브 → 사이트 역동선: 영상 설명란 첫 줄에 `checkup.html?utm_source=youtube&utm_medium=video&utm_campaign=[영상명]` 고정, 고정 댓글에 AI 코치 링크. 사이트 쪽은 UTM 이 있어도 canonical 이 파라미터를 제거하므로 SEO 문제 없음(이미 canonical 설정됨).

### 5-5. 카카오톡 채널 · 네이버 블로그 연동 제안
- **카카오톡 채널**: 한국 상담 리드의 실질 1순위 채널. 제안: 헤더 `상담 신청` 은 유지하고, 모바일 하단 고정 바(≤900px)에 `카톡으로 문의` 버튼 추가 → `[교체: 카카오톡 채널 URL (pf.kakao.com/…)]`. contact.html 연락 정보에도 한 줄. 카카오 채널을 만들면 **채널 추가 = 리드 확보** 가 되므로 자가진단 "안정" 구간의 CTA 로도 사용(§5-2).
- **네이버 블로그**: 한국 검색의 절반 이상이 네이버 → Google SEO 만으로는 부족. 제안: (1) 네이버 서치어드바이저 등록(인증 메타 자리 이미 마련) + sitemap 제출 (2) §7-2 주제로 블로그 글을 쓰고 글 하단에서 자가진단/AI 코치로 링크 (3) 사이트 푸터 "소개·문의" 열에 `블로그 [교체: 네이버 블로그 URL]` 추가, JSON-LD `sameAs` 에 반영. 블로그 글은 사이트 본문을 **복붙하지 말 것**(네이버 유사문서 필터 + Google 중복).
- 인스타그램/스레드는 브리프에 없으므로 제안 보류. 채널 3개(유튜브·카톡·블로그) 이상은 1인 운영자에게 과부하.

## 7. 검색 노출용 콘텐츠 제안

### 7-1. FAQ 초안 (각 페이지 프로그램 섹션 아래, `<details>` 아코디언 권장 — 본문에 실제로 보여야 FAQPage 적용 가능)

브리프 원칙: 의학적 단정·진단·치료 표현 금지("치료합니다", "완치", "장애" 등 사용 안 함). 모두 "훈련", "코칭", "연습" 어휘.

**relation.html — 관계 마음근력 FAQ**

1. **Q. 부부 싸움만 하면 화를 조절하지 못하는데, 상담으로 달라질 수 있나요?**
   A. 관계 마음근력 코칭은 화를 참는 법이 아니라, 상처가 분노로 바뀌어 말로 튀어나오기 전에 **틈을 만드는 훈련**입니다. 마음브레이크 4단계(멈춘다·찾는다·낮춘다·선택한다)를 실제 싸움 장면에 맞춰 연습합니다. 의지의 문제가 아니라 훈련이 비어 있던 자리를 채우는 과정입니다.
2. **Q. 아이한테 화내고 나서 매번 후회해요. 저 같은 부모도 대상인가요?**
   A. 네. '마음잇기'는 부모자녀 갈등을 위한 프로그램입니다. 아이의 반항적인 대답 → 억울함·분노 → 소리치기 → 밤의 자책이라는 고리를 알아차리고, 소리치기 직전에 멈추고 아이의 말을 되풀이해 주는 작은 행동부터 연습합니다.
3. **Q. 배우자가 상담에 같이 오지 않으려고 해요. 혼자서도 가능한가요?**
   A. 가능합니다. '관계 마음근력' 개인 코칭은 한 사람이 자기 패턴을 알아차리고 반응을 선택하는 힘을 기르는 과정입니다. 한 사람의 반응이 바뀌면 고리의 방향도 달라집니다. 부부가 함께할 준비가 되면 '다시, 우리'로 이어갈 수 있습니다.
4. **Q. EFT와 비폭력대화는 어떻게 다른가요?**
   A. EFT는 상처와 분노를 억누르는 대신 인정하고 감정의 세기를 낮추는 기술(CALM 단계)이고, 비폭력대화는 비난 대신 관찰·감정·욕구·부탁의 언어로 바꾸는 기술(CHOOSE 단계)입니다. 감정이 높은 상태에서는 어떤 말도 잘 나오지 않기 때문에, 낮춘 뒤에 말하는 순서로 훈련합니다.
5. **Q. 상담 전에 먼저 해볼 수 있는 게 있나요?**
   A. 관계 트랙 자가진단(8문항, 약 2분)으로 먼저 훈련할 단계를 확인하고, AI 마음브레이크 코치로 지금 이 장면에서 4단계를 연습해 보세요. 둘 다 저장·가입 없이 익명으로 사용할 수 있습니다. 자가진단은 의학적 진단이 아닙니다.

**money.html — 머니 마음근력 FAQ**

1. **Q. 손절을 못 하는 이유가 뭔가요? 의지가 약해서인가요?**
   A. 손실 직후에는 "빨리 복구해야 해", "이번에는 될 거야" 같은 자동생각이 미리 정한 규칙을 밀어냅니다. 의지가 아니라 **손실 → 조급함 → 충동행동** 고리가 자동으로 작동하는 상태입니다. 머니 마음근력 코칭은 이 고리의 '감정 폭발'과 '행동' 사이에 브레이크를 거는 훈련입니다.
2. **Q. 코인·주식 손실 뒤에 멘탈이 무너져 추격매매를 반복합니다. 어떤 훈련을 하나요?**
   A. 세 가지입니다. 복구충동 알아차림(자동생각을 명령이 아닌 신호로 보기), 머니마인드 EFT(돈에 반응하는 불안·흥분·조급함의 세기를 낮추기), 행동 브레이크(매수 버튼 직전에 멈추고 앱 닫기·손절선 적어 두기 같은 행동 고르기). 수익률보다 먼저 '마음의 손절선'을 세우는 것이 목표입니다.
3. **Q. 투자 방법이나 종목을 알려주는 상담인가요?**
   A. 아닙니다. 투자 조언, 종목 추천, 수익 보장은 하지 않습니다. 다루는 것은 손실 앞에서 흔들리는 감정과 충동, 그리고 그 다음 행동입니다.
4. **Q. 도박 문제도 해당되나요?**
   A. 주식·코인·도박의 충동과 복구행동은 같은 고리로 작동하기 때문에 같은 기술로 훈련합니다. 다만 이 코칭은 의료·치료 서비스가 아니므로, 도박으로 인한 어려움이 크다면 한국도박문제예방치유원 헬프라인 1336(24시간)과 함께 이용하시길 권합니다.
5. **Q. 지금 당장 매수 버튼을 누르고 싶은데 어떻게 하죠?**
   A. AI 마음브레이크 코치를 머니 트랙으로 열어 보세요. 매수·추가 입금·다음 베팅을 잠시 보류하고, 감정을 찾고, 6초 호흡으로 낮춘 뒤 행동을 고르는 4단계를 익명으로 안내합니다. 시장은 6초 뒤에도 그 자리에 있습니다.

FAQ 가 본문에 들어가면 E봇이 각 페이지 JSON-LD 에 `FAQPage`(mainEntity Question/Answer 5개) 를 추가한다.
