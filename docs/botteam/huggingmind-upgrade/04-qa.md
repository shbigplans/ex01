## 3. 이슈 목록 (심각도순)

### Major

**Q-01 · Major · `site/assets/js/coach.js:150-151, 230-239`** — 재시작 시 호흡 타이머 미파괴 → 새 세션에 유령 말풍선 주입
- 현상: CALM 호흡 진행 중 `처음부터 다시`를 누르면 `chat.innerHTML=''`만 하고 타이머(RAF)는 계속 돈다. 30초 뒤 이전 세션의 `onComplete`가 실행되어 새 세션(진입 화면)에 "호흡 5라운드 완료", "잘하셨어요. 한 번 더…" 말풍선과 선택지 블록이 삽입된다. 재현 결과: `{"bubbles":["안녕하세요…","호흡 5라운드 완료","잘하셨어요…"],"blocks":1}`.
- 재현: `ai-coach.html?track=relation` → 행동 선택 → 감정 확인 → 욕구 → 마음 낮추기 → `시작` → 즉시 `처음부터 다시` → 31초 대기.
- 제안: `start()`에서 `if (root._breath) root._breath.destroy()`; 세션 토큰(`var session = ++seq`)을 만들어 모든 콜백/`then`에서 `if (session !== seq) return;` 가드.

**Q-02 · Major · `site/assets/js/coach.js:50-66`** — 타이핑 인디케이터 중 재시작 → `removeChild` pageerror + 이전 세션 발화 중복
- 현상: `say()` 대기(400~700ms) 중 `start()`가 `chat.innerHTML=''`로 typing 노드를 지운 뒤, 이전 Promise 가 `chat.removeChild(typing)`을 호출해 `Failed to execute 'removeChild' on 'Node'` 에러가 나고, 이어서 `botBubble()`이 옛 발화를 새 세션에 붙인다. 재현: `?track=money` 로드 직후 100ms 내 `처음부터 다시` → 봇 말풍선 "좋아요…", "지금 어떤 행동…"이 2회 출력, pageerror 1건.
- 제안: Q-01의 세션 토큰 가드 + `if (typing.parentNode) chat.removeChild(typing)`.

**Q-03 · Major · `site/assets/js/reveal.js`, `site/assets/css/base.css:236`** — JS 미동작 시 본문 섹션 전체 미표시
- 현상: `[data-reveal]{opacity:0}`가 무조건 적용되어 JS 비활성/스크립트 로드 실패 시 38개 블록(히어로 이하 전 섹션)이 보이지 않음(`index-1440-nojs.png` — 빈 화면). 검색엔진은 JS 렌더하지만 스크립트 오류·CSP·저사양 환경에서 콘텐츠 전멸.
- 제안: `<html class="no-js">` + `<head>` 인라인 `document.documentElement.classList.replace('no-js','js')`, CSS 를 `html.js [data-reveal]{opacity:0;…}` 로 한정. 또는 `@media (scripting: none){[data-reveal]{opacity:1;transform:none}}` 추가.

**Q-05 · Major · `site/assets/js/checkup.js:108`** — 라디오 `change` 즉시 자동 진행 → 키보드 사용자 문맥 강제 이동(WCAG 3.2.2)
- 현상: 화살표/Space 로 라디오를 고르는 순간 180ms 뒤 다음 문항 카드로 전환되고 포커스가 다음 h2 로 이동(재현: q0 에서 ArrowRight → 카드 1 표시, q0=2 선택됨, 포커스 H2). 화살표로 1→2→3 탐색 자체가 불가능(첫 이동에서 문항이 넘어감). 마우스 사용자에게는 편의지만 키보드/스크린리더에는 예기치 않은 문맥 변경.
- 제안: `pointer` 입력(`click` 이벤트 + `e.detail>0` 또는 `pointerType`)에서만 자동 진행, 키보드 변경은 `다음` 버튼 또는 Enter 로 진행. 최소한 자동 진행 전 `aria-live`로 "다음 문항으로 이동합니다" 안내.

**Q-06 · Major · `site/assets/js/breath.js:153-163`** — 일시정지→재개 시 원 안 문구 '일시정지' 고정
- 현상: `pause()`가 `phase.textContent='일시정지'`로 바꾸지만 `lastPhase`를 초기화하지 않아 재개 후 `render()`의 `ph !== lastPhase` 가 거짓 → 다음 들숨/날숨 전환(최대 3초)까지 '일시정지'가 남고 `aria-live` 낭독도 없음. 재현 로그: `pause text='일시정지' → 400ms after resume text='일시정지'`.
- 제안: `start()`의 paused 분기에서 `lastPhase=''` 리셋(또는 `pause()`에서 별도 오버레이 텍스트 사용).
