## 2. 사이트맵

브리프 권장 7페이지 구성을 그대로 채택한다. 페이지를 합치지 않는 이유: (1) 관계/머니 트랙은 검색 유입 키워드가 완전히 다르므로 별도 URL이 SEO(E봇)에 유리, (2) AI 도구 2종은 공유·재방문(북마크)되는 단독 URL이 필요, (3) 상담/강의 문의는 페이지 하나에 탭 2개로 통합해 폼 관리 지점을 하나로 둔다.

```
/ (index.html)            메인 랜딩 — 브랜드·핵심기술·두 트랙·AI 도구 진입·상담 CTA
├─ relation.html          RELATION FIT 관계 마음근력 (부부·부모자녀)
├─ money.html             MONEY FIT 머니 마음근력 (주식·코인·도박 충동)
├─ ai-coach.html          AI 마음브레이크 코치 (STOP→FEEL→CALM→CHOOSE 대화형)
├─ checkup.html           마음근력 자가진단 (관계 8문항 / 머니 8문항)
├─ about.html             코치 소개 · 저서 『상처를 넘어설 용기』 · 강의 이력
└─ contact.html           문의 (탭: 상담 신청 / 강의·기업교육 문의)
공통 컴포넌트: 6초 호흡 타이머(모달, 모든 페이지에서 호출 가능) · 위기 안내 바
부속: 404.html, sitemap.xml, robots.txt, og-image, favicon 세트, privacy.html(개인정보처리방침 [교체: 사업자 정보])
```

URL·파일명은 위와 같이 고정(C봇·E봇 공통 기준).

## 3. 메인 페이지(index.html) 섹션 구성

> 카피 원칙: 브리프의 PDF 원문을 최대한 그대로 살리고, 조사·리듬만 프리미엄 톤으로 다듬는다. 헤드라인은 2줄 이내, 서브카피는 3문장 이내.

### S1. 히어로
- **목적**: 3초 안에 "무엇을 훈련하는 사람인가"를 각인. 첫 스크롤 없이 두 트랙과 AI 체험 진입점 노출.
- **헤드라인(최종)**: **돈과 관계 앞에서 흔들리는 마음을 훈련합니다.**
- **서브카피**: 감정은 인정하고 · 충동은 멈추고 · 행동은 내가 선택하도록.
  나영채 | 감정·충동조절 마음근력 코치
- **CTA**: 주 `AI 마음브레이크 체험하기` → ai-coach.html / 부 `내 마음근력 진단하기` → checkup.html
- **구성 요소**: 상단 오버라인 "BLISS MIND FIT", 대형 에디토리얼 헤드라인, 서브카피 3구(중점 구분자), CTA 2개, 우측(모바일 하단) 인물 사진 `[교체: 나영채 코치 프로필 사진, 3:4]`, 하단 스크롤 힌트 + 두 트랙 태그 칩(`RELATION FIT` / `MONEY FIT`).

### S2. 문제 공감 (두 개의 고리)
- **목적**: 방문자가 자신의 패턴을 즉시 발견하게 한다. 트랙 분기 시작점.
- **헤드라인**: 문제는 감정이 아니라, 감정과 행동 사이의 '거리'입니다.
- **서브카피**: 상처와 손실은 피할 수 없습니다. 그러나 그 다음에 오는 행동은 훈련할 수 있습니다.
- **CTA**: 각 카드 하단 `관계 마음근력 보기` / `머니 마음근력 보기`
- **구성 요소**: 2열 카드.
  - 카드 1 RELATION: 흐름도 `상처 → 감정 폭발 → 공격·회피 → 관계 악화` + 한 줄 "부부·부모자녀의 분노, 상처, 갈등, 소통"
  - 카드 2 MONEY: 흐름도 `손실 → 감정 폭발 → 충동행동 → 추가 손실` + 한 줄 "주식·코인·도박의 충동, 복구행동, 손실 후 감정조절"
  - 두 흐름의 '감정 폭발 → 행동' 사이에 공통 하이라이트 마커 "여기가 개입지점입니다."

### S3. 핵심기술 — 마음브레이크
- **목적**: 브랜드의 필살기를 4단계로 시각화. AI 코치와 동일한 어휘 체계 확립.
- **헤드라인**: 마음브레이크 — 감정과 행동 사이에 틈을 만드는 기술
- **서브카피**: 참으라고 가르치지 않습니다. 충동과 행동 사이에 틈을 만드는 훈련입니다.
- **CTA**: `AI 코치와 4단계 연습하기` → ai-coach.html
- **구성 요소**: 4단계 스텝 레일(가로, 모바일 세로). 각 스텝 = 번호 + 영문 키워드 + 한글 동사 + 설명 1줄.
  1. **STOP 멈춘다** — 충동행동을 잠시 보류합니다.
  2. **FEEL 찾는다** — 지금의 감정과 욕구를 확인합니다.
  3. **CALM 낮춘다** — 6초 호흡 + EFT로 강도를 낮춥니다. *(인라인 미니 호흡 타이머 버튼 "6초만 해보기" → 호흡 모달)*
  4. **CHOOSE 선택한다** — 감정이 아닌 내가 행동을 선택합니다.
  하단 보조 3구: 감정 알아차림 / 마음 안정(6초 호흡 + EFT) / 행동 선택.

### S4. RELATION FIT 관계 마음근력
- **목적**: 페르소나 A 대상 트랙 요약과 서브페이지 유도.
- **헤드라인**: 다시, 우리. 상처가 폭발이 되기 전에 마음을 말하는 법.
- **서브카피**: 상처 → 분노·억울함 → [마음브레이크] → 마음 말하기 → 연결.
- **CTA**: `관계 마음근력 자세히` → relation.html / `관계 진단 해보기` → checkup.html#relation
- **구성 요소**: 좌 작동 흐름 다이어그램, 우 3개 기술 카드 — EFT(상처와 분노를 억누르기보다 인정하고 감정의 강도를 낮춘다) / 비폭력대화(비난 대신 관찰·감정·욕구·부탁의 언어로 바꾼다) / 관계 선택(공격하거나 회피하는 자동반응 대신 연결되는 행동을 선택한다). 프로그램 태그: "다시, 우리" · "마음잇기" · "관계 마음근력".

### S5. MONEY FIT 머니 마음근력
- **목적**: 페르소나 B 대상. 브리프의 강력한 카피를 헤드라인으로.
- **헤드라인**: 수익률보다 먼저, 마음의 손절선을 세웁니다.
- **서브카피**: 손실 → 조급함·만회욕구 → [마음브레이크] → 평정 → 행동 선택.
- **CTA**: `머니 마음근력 자세히` → money.html / `머니 진단 해보기` → checkup.html#money
- **구성 요소**: S4와 대칭 레이아웃(좌우 반전). 3개 기술 카드 — 복구충동 알아차림("빨리 복구해야 해" "이번에는 될 거야" 같은 자동생각과 감정을 포착) / 머니마인드 EFT(돈에 반응하는 불안·흥분·억울함·조급함을 낮추는 EFT 훈련) / 행동 브레이크(추격매매·과도한 베팅 등 충동행동 직전에 멈춤과 선택을 훈련).

### S6. AI 도구 쇼케이스
- **목적**: 사이트의 차별 요소인 AI 기능 3종을 한 화면에서 체험 유도.
- **헤드라인**: 지금, 이 자리에서 시작하는 훈련.
- **서브카피**: 상담 전에도 마음브레이크는 작동합니다. 익명으로, 저장 없이.
- **CTA**: 카드별 `코치 시작` / `진단 시작` / `호흡 시작`
- **구성 요소**: 3카드 — ① AI 마음브레이크 코치(4단계 대화 미리보기 말풍선 2개) ② 마음근력 자가진단(8문항·약 2분·즉시 리포트) ③ 6초 호흡 타이머(카드 안에서 바로 실행되는 원형 애니메이션). 하단 소형 안내: "입력 내용은 브라우저에만 머물며 서버로 전송되지 않습니다(v1 기준)."

### S7. 왜 나영채인가 (경력 어필 5축)
- **목적**: 신뢰 형성. 브리프 5축을 그대로 구조화.
- **헤드라인**: 이해에서 끝나지 않고, 행동이 바뀔 때까지.
- **서브카피**: 보호관찰 현장에서 EFT 기반 감정조절 교육까지 — 분노와 충동을 실제 행동 선택으로 연결해 온 경험.
- **CTA**: `코치 소개 보기` → about.html
- **구성 요소**: 5개 항목 리스트(아이콘 없이 번호·키워드·설명): 현장성 / 전문기술 / 행동변화 / 확장성 / 저자·강의. 우측 저서 표지 `[교체: 『상처를 넘어설 용기』 표지 이미지]` + 저자 한 줄. 수치형 지표(경력 년수·수강생 수 등)는 `[교체: 확인된 수치 있을 때만 추가]`로 빈 슬롯 두지 않고 생략.

### S9. 후기·강의 실적 *(조건부 섹션)*
- **목적**: 사회적 증거. **실제 자료가 들어올 때만 노출**, 없으면 섹션 숨김(빈 후기·가짜 후기 절대 금지).

- **구성 요소**: `[교체: 실제 수강 후기 2~3건(동의 받은 것)]`, `[교체: 강의 기관 로고/명칭]`.

## 5. AI 기능 스펙

### 5-a. AI 마음브레이크 코치 (ai-coach.html)

#### 공통 설계
- 화면: 채팅형 UI(봇 말풍선 좌 / 사용자 선택 우). 자유 입력창은 FEEL 단계에서만 선택적으로 노출(v1은 입력해도 저장·분석하지 않고 다음 단계로만 넘김, v2는 LLM에 전달).
- 상단 진행 표시: `STOP · FEEL · CALM · CHOOSE` 4점 스텝퍼, 현재 단계 강조.
- 상태 저장: 세션 중에는 메모리만. 종료 시 `sessionStorage`에 마지막 요약 카드만(선택). 서버 저장 없음.
- 진입 파라미터: `?track=relation|money`가 있으면 트랙 선택 화면 생략.
- 봇 응답 지연: 400~700ms 타이핑 인디케이터(모션 감소 설정 시 즉시 표시).
- 모든 버튼은 `<button>`으로, 키보드 포커스 순서 = 화면 순서.

#### 대화 흐름 및 스크립트 (v1 규칙 기반 — 그대로 구현)

- 선택지: `[관계 — 가족, 배우자, 아이와의 일]` `[돈 — 투자, 손실, 베팅 충동]` `[잘 모르겠어요]`

  - 무력감: "무력감은 '뭘 해도 소용없을 것 같다'는 마음이에요. 지금은 판단이 아니라 회복이 먼저입니다."

### 5-b. 마음근력 자가진단 (checkup.html)

#### 문항 (5점 리커트: 1 전혀 그렇지 않다 · 2 그렇지 않다 · 3 보통이다 · 4 그렇다 · 5 매우 그렇다)
모든 문항은 "흔들림"을 묻는 방향으로 통일(역채점 없음 → 구현 단순화). 점수가 높을수록 훈련 필요.

**관계 트랙 (R1~R8)** — 최근 한 달 기준
1. R1. 배우자나 자녀의 한마디에 순식간에 화가 치밀어 오른다.
2. R2. 화가 나면 나중에 후회할 말을 먼저 내뱉는다.
3. R3. 갈등이 생기면 대화 대신 입을 닫거나 자리를 피한다.
4. R4. 상대가 나를 무시한다고 느끼면 억울함이 오래 간다.
5. R5. 내가 무엇을 느끼는지보다 상대의 잘못이 먼저 떠오른다.
6. R6. 감정이 격해질 때 몸(호흡·심장·손)의 변화를 알아차리지 못한다.
7. R7. 상대에게 내 감정과 바람을 비난 없이 말하기가 어렵다.
8. R8. 같은 패턴의 싸움이 반복되는데 멈추는 방법을 모르겠다.

**머니 트랙 (M1~M8)** — 최근 한 달 기준
1. M1. 손실이 나면 "빨리 복구해야 한다"는 생각이 머리를 떠나지 않는다.
2. M2. 손실 직후 계획에 없던 추가 매수나 베팅을 한 적이 있다.
3. M3. 미리 정한 손절선이나 한도를 지키지 못한다.
4. M4. 수익이 나면 흥분해서 규모를 갑자기 키운다.
5. M5. 시세를 확인하지 않으면 불안해서 다른 일에 집중하기 어렵다.
6. M6. 손실을 가족이나 가까운 사람에게 숨긴다.
7. M7. "이번에는 될 거야"라는 생각으로 근거 없이 다시 들어간다.
8. M8. 돈 문제로 인한 조급함·억울함을 낮추는 나만의 방법이 없다.

#### 채점 로직
- 합산 점수 S = 8문항 합계, 범위 8~40.
- 구간:
  - **안정**: 8 ~ 17
  - **주의**: 18 ~ 28
  - **훈련 필요**: 29 ~ 40
- 표시용 마음근력 지수 = `Math.round((40 - S) / 32 * 100)` (0~100, 높을수록 단단함). 게이지에 구간 경계(안정 ≥ 72, 주의 38~71, 훈련 필요 ≤ 37)를 함께 표시.
- 보조 진단(개입지점): 문항을 3묶음으로 매핑해 가장 높은 묶음을 '먼저 훈련할 단계'로 표시.
  - 관계: 알아차림 {R5, R6} / 안정 {R1, R4, R8} / 선택 {R2, R3, R7}
  - 머니: 알아차림 {M1, M5, M7} / 안정 {M4, M8} / 선택 {M2, M3, M6}
  - 동점이면 알아차림 → 안정 → 선택 순 우선.
- 미응답 문항이 있으면 결과 버튼 비활성 + 해당 문항으로 스크롤.
- 결과는 서버 전송 없음. URL 해시로 공유 가능하게 `#result=R-23`(트랙-점수)만 인코딩(개별 응답은 포함 안 함).

### 5-c. 6초 호흡 타이머 (공통 컴포넌트 `breath.js`)

- **UI**:
  - 중앙 원: 들숨 시 scale 1 → 1.35(3s ease-in-out), 날숨 시 1.35 → 1. 원 안 텍스트 "들이쉬세요 / 내쉬세요", 아래 초 카운트 3·2·1, 라운드 표시 "2 / 5".

## 8. 성공 기준 (QA 체크리스트)

1. 7개 페이지 + 404가 400px·768px·1024px·1440px에서 가로 스크롤 없이 렌더링되고, 헤더 CTA·햄버거 메뉴가 모바일에서 동작한다.
2. 히어로에 슬로건 "돈과 관계 앞에서 흔들리는 마음을 훈련합니다."가 `h1`로 존재하고, 각 페이지 `h1`이 1개다.
3. 다크/라이트: 시스템 설정 자동 반영 + 토글 저장(localStorage), 두 테마 모두에서 본문 대비 4.5:1 이상(Lighthouse 접근성 ≥ 95).
4. AI 코치 v1: 네트워크 차단 상태에서 STOP→FEEL→CALM→CHOOSE 전 흐름이 관계/머니/일반 3트랙 모두 완주되고, 요약 카드가 생성된다. 안전 키워드 입력 시 위기 카드가 즉시 뜬다.
5. 자가진단: 두 트랙 각 8문항, 미응답 시 결과 차단, 경계값(17/18, 28/29)이 정확한 구간으로 분류되고 6개 결과 문구가 모두 표시된다.
6. 호흡 타이머: 5라운드 완료까지 30초(±0.5초), 일시정지/중단/재시작 동작, `prefers-reduced-motion`에서 스케일 애니메이션 비활성, CALM 단계 완료 콜백이 다음 말풍선을 연다.
7. 폼 2종: 필수 필드 미입력 시 인라인 오류, 전화 패턴 검증, honeypot 동작, 제출 후 확인 메시지 표시(엔드포인트 미설정 시 mailto 폴백).
