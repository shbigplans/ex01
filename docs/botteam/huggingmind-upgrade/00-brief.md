# 00. 킥오프 브리프 — huggingmind.kr 프로 업그레이드

작성: 오케스트레이터 · 2026-09-11

## 프로젝트 재정의

나영채 코치의 상담·코칭 브랜드 사이트 https://huggingmind.kr 을 "700만 원 이상 외주 제작 수준"의 세련된 브랜드 사이트로 재구축한다.
기존 사이트의 기본 내용(소개, 프로그램)은 유지하되, 첨부 포지셔닝 문서(8p 스캔본)를 단일 진실 소스로 삼아 카피와 구조를 재편하고, AI 기반 인터랙티브 기능을 추가한다.

프로젝트 유형: 홈페이지 제작(리뉴얼). 스택: 정적 HTML + CSS + 최소 JS (프레임워크 없음). AI 기능 중 LLM 호출이 필요한 부분은 서버리스 함수 코드로 제공하되 배포는 사용자 확인 후.

## 제약

- 기존 사이트는 이 세션의 네트워크 정책(egress)에 막혀 열람 불가. 따라서 기존 콘텐츠는 PDF 자료 기준으로 재구성한다. 사용자가 기존 사이트의 추가 자료(사진, 연락처, 프로그램 가격)를 주면 반영한다.
- 실제 인물 사진·연락처·프로그램 가격은 자료에 없으므로 플레이스홀더로 두고 교체 지점을 명시한다.

## 요구사항

1. **프리미엄 완성도**: 에디토리얼 타이포그래피, 절제된 모션, 정교한 간격 체계. 템플릿 티가 나지 않을 것.
2. **AI 기능** (요즘 핫한 AI를 브랜드 핵심기술과 결합):
   - AI 마음브레이크 코치: STOP→FEEL→CALM→CHOOSE 4단계를 대화형으로 안내. 1차는 클라이언트 사이드 가이드 흐름(키 없이 동작), LLM 연동은 서버리스 함수 코드로 제공.
   - 마음근력 자가진단: 관계/머니 두 트랙 문항 → 즉시 결과 리포트 + 맞춤 프로그램 추천.
   - 6초 호흡 인터랙티브 타이머(CALM 단계 체험).
3. **필수 기본**: 반응형(400~1440px), 다크/라이트, OG/메타, favicon, 접근성, 상담 신청 폼, 저서 소개, 강의·기업교육 문의.
4. **산출물**: 디자인 캔버스(Claude Design) + 정적 사이트 코드 + QA 리포트 + 봇 대화 로그.
