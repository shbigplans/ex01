## 3. 적용 방식 선호 (하나 선택)

- ( ) **위젯 방식** — 기존 페이지에 `<script>` 한 줄 + `<div>` 한 개 붙이면 동작하는 독립 번들. 기존 사이트를 거의 건드리지 않음. (플랫폼 불문, 가장 안전)
- ( ) **서브도메인 방식** — `tools.huggingmind.kr` 같은 별도 정적 사이트에 기능 페이지를 올리고 기존 사이트에서 링크. (기존 사이트에 스크립트 삽입이 불가할 때)
- ( ) **직접 수정 방식** — 기존 소스 코드를 저장소에 넣고 봇팀이 직접 페이지를 고침. (소스 접근이 있을 때, 가장 자연스러움)
- ( ) 모르겠음 → 봇팀이 1번 표를 보고 판단
